# Solicitação Reversa

Projeto para automação e gestão de solicitações de logística reversa.

## Estrutura do Projeto

- `docs/`: Documentação e planejamento do projeto.
- `modelos/`: Planilhas Excel de referência e modelos de dados.
- `scripts/`: Scripts utilitários e ferramentas de suporte.
- `.agents/`: Configurações e habilidades dos agentes Antigravity.

## Tabelas no Banco de Dados (Supabase)

1. `reversa`: Baseada no modelo de baixo giro.
2. `connect_reversa`: Baseada no modelo de estoque net.
